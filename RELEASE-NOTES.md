# PS4 Package Studio for Windows

This standalone release brings the PS4 Package Studio from the combined edition into its own Windows application. Download the ZIP, extract it, and run **PS4 Package Studio.exe**.

## Features in this release

- Build PS4 Classics fPKGs from supported PS1 CUE/BIN or raw 2352-byte ISO images and PS2 DVD ISOs.
- Queue games for sequential package creation or use supported multi-disc mode.
- Review detected IDs, disc checks, artwork, game settings, and the PS4 home-screen preview before building.
- Apply supported PS1 patches, PS1 emulator settings, PS2 Lua profiles, custom configurations, and supported automatic widescreen patches.
- Use offline disc catalogs and cached artwork, with optional online cover and manual lookup.
- Preview PS2 manuals on the PC. Manuals are excluded from the PS4 package.
- Follow build activity, progress and estimated time where available, cancellation, and the completed output location.
- Use the bundled packaging resources and Windows runtime without a separate Python, .NET, or packaging-app installation.
- Includes the custom electric-blue PS4 console and package Windows icon.

The application was launched on Windows during the release check. Console gameplay was not verified. See the README for detailed supported formats, workflow limitations, and credits.

Redistribution rights for the bundled PS4 emulator components, PS4 package tool, and inherited PS3 placeholder license have not been confirmed.
